# 🛒 Bazar Dor — বাজার দর

**Bazar Dor** is a Bangladeshi daily necessities price tracking web application that helps users explore essential products, check their prices, and understand price changes.

## 📌 Project Overview

Bazar Dor makes it easier to explore everyday grocery and household product prices through a responsive and user-friendly interface. Users can browse products, filter by category, view product details, and access personalized features by signing in.

## ✨ Features

* 📱 **Responsive Design:** Works on mobile, tablet, and desktop screens.
* 🛍️ **Product Listing:** Browse daily necessities and their current prices.
* 📊 **Price Tracking:** View price changes and identify products with increasing or decreasing prices.
* 🗂️ **Category Filtering:** Explore products by category.
* 🔎 **Product Details:** Open individual product pages for more information.
* 🔐 **Authentication:** Sign up and sign in using Better Auth.
* 🌐 **Social Login:** Google and GitHub sign-in options.
* 👤 **User Profile:** Access profile information and update your name.
* 🚪 **Logout:** Securely end your authenticated session.
* 🔒 **Protected Routes:** Restrict access to pages that require authentication.
* 🔔 **Toast Notifications:** Display feedback for relevant user actions.
* ⏳ **Loading States:** Provide loading feedback while content is being fetched.

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Better Auth
* MongoDB
* Lucide React
* React Hot Toast


## 🔐 Authentication and Security

Bazar Dor uses Better Auth for authentication and supports email/password authentication and configured social login providers.

Environment variables containing secrets must remain private. The `.env.local` file should not be uploaded to GitHub.

## 📱 Responsive Experience

The interface is designed to adapt to different screen sizes, helping users browse product information on desktop computers, tablets, and mobile devices.
